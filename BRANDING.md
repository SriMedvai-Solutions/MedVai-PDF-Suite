# Branding and logo customization

## Using your own logo

You may replace the bundled logo for personal or internal use:

1. Replace `assets/logo.png` with your header logo.
2. Replace `assets/logo.ico` with your Windows icon.
3. Keep the filenames unchanged.
4. Rebuild the EXE using `MedVai_PDF_Suite.spec`.

Recommended files:

- PNG: transparent background, clear at approximately 88–110 pixels high.
- ICO: include common Windows sizes such as 16, 32, 48, 128, and 256 pixels.

The source run will use the new PNG immediately. The Windows EXE icon changes only after rebuilding the EXE.
