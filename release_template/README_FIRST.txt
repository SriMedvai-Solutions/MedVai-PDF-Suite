MedVai PDF Suite - Windows x64

MedVai PDF Suite is completely free, open-source, and designed to process PDFs offline.

BASIC USE
1. Extract the ZIP.
2. Run MedVai_PDF_Suite.exe.
3. Review the generated PDF and Audit DOCX before using output in a legal or production matter.

WINDOWS SECURITY NOTICE
The EXE is not digitally signed. Windows Defender SmartScreen or another antivirus may show Unknown publisher, block the file, or ask for confirmation.

Before running it:
1. Download it only from the official MedVai PDF Suite GitHub Release.
2. Scan the ZIP or EXE with Microsoft Defender or your antivirus.
3. Compare the EXE SHA-256 value with SHA256.txt included in this ZIP.
4. Right-click the downloaded ZIP, choose Properties, select Unblock if shown, and choose Apply. Then extract it again.
5. If the EXE still shows Unblock in Properties, select it and choose Apply.
6. If SmartScreen shows Windows protected your PC, choose More info > Run anyway only after the official source and SHA-256 value are confirmed.

Do not disable your antivirus. On a company-managed computer, contact your IT administrator if the application is blocked.

To verify the checksum in PowerShell:
Get-FileHash .\MedVai_PDF_Suite.exe -Algorithm SHA256
