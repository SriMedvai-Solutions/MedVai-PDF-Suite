# Security policy

## Reporting a security issue

Do not post a public issue containing private PDFs, medical records, client names, passwords, or sensitive paths.

Report the problem privately to Ramakrishnan Chinnasamy through LinkedIn:

https://www.linkedin.com/in/ramakrishnan-chinnasamy-558321b/

Include only the minimum technical information needed. Use a synthetic PDF where possible.

## Privacy model

MedVai PDF Suite is designed to process PDFs locally. It does not intentionally upload PDFs or require an online service. Users are still responsible for protecting their computer, output folder, temporary files, backups, and shared documents.

## Supported release

Security fixes are normally applied to the latest public beta or stable release.
