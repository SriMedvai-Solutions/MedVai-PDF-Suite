# Changelog

## 3.0.5-beta — First public beta

- Added offline PDF merge and split workflows.
- Added natural PDF ordering and a separate PDF arrangement window.
- Added continuous and selective Bates modes.
- Added continuous merged-page numbering and page-number patterns.
- Added separate Bates and numbering placement previews.
- Added rotation-aware and mixed-page-size placement.
- Added per-page stamp verification and disclosed hard-stamp fallback.
- Added strict split-range validation.
- Added automatic output naming and overwrite protection.
- Added a human-readable Audit DOCX.
- Moved technical CSV maps and logs into `Technical_Audit_Files`.
- Added public documentation, AGPL licence, automated tests, and GitHub release files.
